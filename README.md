# Daysavvy API Task - Daily Task Scheduler

This is a Python Flask API that creates an optimized daily timeline based on task priority.

## Features
- Add task: name, duration, priority (1-5)
- Auto schedule tasks
- Daily analytics

## Tech Stack
- Python, Flask, SQLite

## How to Run
pip install -r requirements.txt
python app.py

API will run on http://127.0.0.1:5000
